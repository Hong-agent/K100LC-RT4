# K100 标准版驱动（rock-5.7.1）在 Ubuntu 22.04 / 内核 6.8 上的编译修正说明

## 现象

原始安装包 `rock-5.7.1-6.2.35-V1.6.7.aio.run` 在本机（Ubuntu 22.04.5，
HWE 内核 `6.8.0-40-generic`）上编译失败，日志 `install-1.log` 结尾为
`driver build fail`，报错：

```
include/kcl/backport/kcl_drm_print.h:53:6: error: redeclaration of 'enum drm_debug_category'
./include/drm/drm_print.h:278:6: note: originally defined here
```

## 根因

驱动用 autoconf 探测内核是否已提供 `enum drm_debug_category`
（探测宏 `AC_HYDCU_DRM_DEBUG_CATEGORY`，见
`amdgpu-5.7.0-0/amd/dkms/m4/drm_debug_enabled.m4`）。探测编译使用
`EXTRA_CFLAGS="-Werror ..."`（见 `amd/dkms/m4/kernel.m4:534`），
而探测代码里的辅助函数没有原型，在 6.8 内核的 `-Werror=missing-prototypes`
下被判为错误：

```
conftest.c:354:30: error: no previous prototype for 'test_enum' [-Werror=missing-prototypes]
```

于是 **内核明明有这个 enum，探测却误判为"没有"**，驱动的 KCL 兼容层
又自己定义了一遍，与内核头文件里的定义冲突 → 整个驱动编译失败。

## 修正内容

只改 1 个文件：`amdgpu-5.7.0-0/amd/dkms/m4/drm_debug_enabled.m4`

```diff
 		AC_KERNEL_TRY_COMPILE([
 			#include <drm/drm_print.h>
-			void test_enum(enum drm_debug_category arg) {
-			}
 		],[
-			enum drm_debug_category t;
-			test_enum(t);
+			enum drm_debug_category t = DRM_UT_CORE;
+			(void)t;
 		],[
 			AC_DEFINE(HAVE_DRM_DEBUG_CATEGORY,
 				1,
 				[enum drm_debug_category is available])
```

去掉会触发 `-Wmissing-prototypes` 的辅助函数，只保留"该类型是否存在"这一
探测语义。修正后 `HAVE_DRM_DEBUG_CATEGORY` 被正确置为 1，KCL 不再重复定义。

## 验证结果（2026-09-25 实测）

- 修正前：`configure` 输出 `/* #undef HAVE_DRM_DEBUG_CATEGORY */`，编译报错中断。
- 修正后：`configure` 输出 `#define HAVE_DRM_DEBUG_CATEGORY 1`，按
  `pre-build.sh` → `configure` → `make` 的完整流程重新编译，
  **exit 0、0 error**，产出全部 7 个模块：

  | 模块 | 大小 |
  |---|---|
  | amd/amdgpu/hydcu.ko | 101M |
  | ttm/hyttm.ko | 3.2M |
  | extra/hy-extra.ko | 2.6M |
  | amd/amdkcl/hykcl.ko | 1.8M |
  | scheduler/hydcu-sched.ko | 1.2M |
  | hydrm_ttm_helper.ko | 379K |
  | hydrm_buddy.ko | 290K |

  仅 `DRM_UT_CORE` 一处语义，`modinfo hydcu.ko` 显示 `version: 6.2.35`、
  `description: HYGON DCU`。

## 文件对照

| 文件 | 用途 |
|---|---|
| `rock-5.7.1-6.2.35-V1.6.7.aio.run` | 原厂包（未改动，保留） |
| `rock-5.7.1-6.2.35-V1.6.7-内核68修正.aio.run` | **修正版**，除上述 1 个文件外与原包完全一致（MD5 `6ce38851cd21478ab669c9ff6b5e45d2`） |
| `../03_scripts/99_fix_driver_k100_std.sh` | 一键修正脚本：卸掉错驱动 + 装本包 + 固定启动内核 |

## 使用

```bash
# 在 K100 包目录下执行（脚本会自动定位同级目录，放哪都行）
sudo bash 03_scripts/99_fix_driver_k100_std.sh
sudo reboot
/opt/hyhal/bin/hy-smi     # 重启后验证
```

注意：驱动只针对"安装时正在运行的内核"编译。本机 GRUB 默认会启动
`6.8.0-138-generic`（该内核下没有驱动模块和固件），脚本会把默认启动项
改回安装时所在的内核；以后每次升级内核后都需要重新装一次驱动。
